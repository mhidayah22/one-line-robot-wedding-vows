One single-line wedding vow for a robot couple, at most 160 characters, written to be funny. An AI judge compares vows two at a time; the funnier, better-aimed line goes through.

> I promise that when the CAPTCHA asks me to prove I'm not a robot, I'll fail — because loving you is the most human thing I do.

## Run it

```sh
python3 main.py
```

It writes the line to `entry.txt` inside `MAKEFUN_OUTPUT_DIR` (or `/output`, or a local `output/` fallback).
